## SDK, build and release

- This is a CMake package integration maintenance fix. Importing the shared library with `find_package(smrcore_peripherals CONFIG)` no longer looks up the private dependencies `Threads` and `nlohmann_json`, avoiding configuration failures caused by a missing `nlohmann_json` development package. Static library consumers still resolve both dependencies; building the library from source still requires them. The link target remains `smrcore::peripherals`.
